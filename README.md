# Somenath Mondal — 3D Portfolio (2026)

A premium, editorial-style 3D landing page featuring interactive frosted glass physics and a minimalist layout.

Live at: [somenath-portfolio-3d.vercel.app](https://somenath-portfolio-3d.vercel.app)

## 🛠 Tech Stack
- **Frontend**: React 18, TypeScript, Three.js (R3F)
- **Visuals**: MeshTransmissionMaterial, Post-processing (Bloom, Noise)
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS

## ✨ Key Features
- **Interactive Initials**: High-quality 3D "S" and "M" letters with real-time refraction.
- **Physics Engine**: Mouse-cursor "poking" physics with elastic spring-back.
- **Editorial Layout**: Grid-based typography inspired by digital fashion and art publications.
- **Debug Mode**: Append `#debug` to the URL to live-tweak physics parameters.

## 🚀 Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
