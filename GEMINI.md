# Somenath Portfolio Instructions

A professional 3D portfolio with a full-stack architecture.

## Tech Stack
- **Frontend**: React 18, TypeScript, Three.js (R3F), Framer Motion, Tailwind CSS.
- **Backend**: Node.js, Express, Drizzle ORM, PostgreSQL.

## Workflows
- Use `npm run dev` to start the project.
- Database schema and server-side code have been removed to keep the project lean.
